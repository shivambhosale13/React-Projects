# 💼 Digital Business Card

A responsive digital business card built with **React.js**. This project was created as part of my React learning journey to practice component-based development and styling.

## 🚀 Features

* Personal profile section
* Profile image
* Email button with icon
* LinkedIn button with icon
* About section
* Interests section
* Footer with social links
* Clean and modern card layout

## 🛠️ Technologies Used

* React.js
* JavaScript
* JSX
* HTML5
* CSS3
* Vite
* Font Awesome

## 📚 React Concepts Practiced

* React components
* JSX
* Component imports and exports
* `createRoot()`
* Rendering components
* Component composition
* CSS styling
* Flexbox
* Font Awesome icons

## ▶️ How to Run

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd Digital-Business-Card
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL provided by Vite in your browser.

The main goal of this project was to get hands-on experience with React and understand how a UI can be broken down into reusable components.
